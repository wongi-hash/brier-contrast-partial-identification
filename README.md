# Reproducibility package (results & tables)

**Comparing Survival Prediction Models without Target Outcomes: Sharp Partial
Identification of Direct Brier-Risk Contrasts under Conditional Outcome Shift**

This package reproduces the **numerical results and tables** of the paper: the
simulation studies and the locked, derived result files behind the manuscript
tables. No patient-level data are included. Figure-drawing code and rendered
figure files are intentionally outside this results-and-tables package.

## Included
- **Simulation / analysis code**
  - `final_sim/RUN_COMPARATOR_APPMATCHED_SIM_V2.py`, `final_sim/AGGREGATE_COMPARATOR_6080.py`
    — application-scale comparator study (Table 1; Table S6).
  - `code/RUN_DIRECT_SEPARATE_HARMONIZATION_C4_20260902.py`
    — Rotterdam→GBSG direct-vs-separate analysis (Table S4).
  - `code/coverage_FROM_CODEX/` — the executed coverage runners, portable shard
    launchers, decision-regime runner, horizon-sensitivity runner, locked/executed
    configurations, environment provenance, and final summaries (Tables S5, S9,
    S10).
  - `code/RUN_NSCLC_HONEST_SPLIT_SHARP_CONTRAST.py` — generic downstream NSCLC
    sharp-contrast analysis with an analysis-side outcome firewall. The restricted
    institutional inputs required for an exact application rerun are not included.
- **Derived result files** (no patient-level data)
  - `final_sim/COMPARATOR_6080_AGGREGATED.csv` — comparator aggregates (Table 1, Table S6).
  - `direct_separate_harmonized_20260902/harmonized_direct_separate.csv` — Rotterdam decisions (Table S4).
  - `ctdate_60_80_results/direct_separate_59_80_vs_60_80.csv` — NSCLC direct-vs-separate (Table 3 / §4.6).
  - `pending_BDS7_20260907_results/B/AGG_*.json` — decision-regime frequencies (Table S5).

## NOT included (by design)
- **No patient-level or raw imaging data** (CNUHH individual-level data are not public).
- Raw external datasets are **not redistributed** — use the original sources:
  - Stanford & VA: TCIA NSCLC-Radiogenomics — https://doi.org/10.7937/K9/TCIA.2017.7hs46erv
  - Rotterdam & GBSG: `rotterdam` / `gbsg` in the R `survival` package.
- **Figure-drawing code and rendered figures** are not part of this results package.
- Large per-replicate simulation checkpoints (regenerated by the runners).
- The locked NSCLC feature tables and upstream SparsePCA artifacts are not
  redistributed. The repository contains the generic downstream runner and the
  non-individual-level derived result table only.

## Requirements
The locked execution used Python 3.8.5, NumPy 1.24.3, pandas 2.0.3, and SciPy
1.10.1. These versions are pinned in `requirements.txt`; expanded provenance and
runtime hashes are in `code/coverage_FROM_CODEX/ENVIRONMENT_PROVENANCE.json`.

## Reproduce
See `RUN_ORDER.md` for the script → table mapping and commands. In brief:
```bash
pip install -r requirements.txt
# comparator study (Table 1, S6):
python final_sim/RUN_COMPARATOR_APPMATCHED_SIM_V2.py
python final_sim/AGGREGATE_COMPARATOR_6080.py
# coverage tables (S9); use the parallel launchers for the full locked run:
python code/coverage_FROM_CODEX/run_task_e_parallel.py
python code/coverage_FROM_CODEX/run_task_e2_parallel.py
```

The committed locked S9 summaries reproduce two-sided coverages
`0.859 / 0.847 / 0.943` and outer-envelope coverages
`0.861 / 0.847 / 0.946` for target sizes 60, 80, and 686, respectively.
See `VALIDATION_REPORT.md` for the public-package audit and locked numerical
cross-checks.

## Application-data boundary
The NSCLC and Rotterdam/GBSG result tables are provided only as derived,
non-individual-level summaries. Exact real-data reruns require obtaining the
source datasets from their custodians and reconstructing the prespecified locked
inputs. The public runners accept those inputs but this repository does not
redistribute them.
